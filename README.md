> **TikTok Autopilot** est la machine automatisée conçue pour **Karl** afin de découper, habiller et publier des vidéos courtes à fort impact spirituel à partir de prédications d'hommes de Dieu chrétiens. Le système transforme de longs cultes et enseignements en TikToks 9:16 verticaux percutants, avec sous-titres mot-à-mot, bannières prophétiques et publication directe sur TikTok.

---

## 🎯 Le Flux 100% Autonome pour Karl

```text
1. Karl dépose le lien de la prédication (YouTube, Facebook, vidéo...)
                                  │
                                  ▼
           🤖 L'ÉQUIPE AUTONOME PREND LE RELAIS :
           1. DevOps-Bot télécharge et lance l'usine dans le Cloud
           2. Media-Bot repère les punchlines spirituelles (30 à 60s)
              applique le format 9:16 + Thème Gospel + Barre dorée animée
           3. Growth-Bot génère le Hook ("ÉCOUTE CE MESSAGE PROPHÉTIQUE 🕊️")
              + légende chrétienne avec appel au commentaire "AMEN"
              + hashtags ciblés (#chretien #cotedivoire #abidjan #foi)
           4. TikTok Publisher envoie la vidéo directement sur TikTok
              (Mode Brouillon Privé pour vérification ou Public Direct)
                                  │
                                  ▼
✨ Vidéo prête sur TikTok sans aucun montage manuel requis de ta part !
```

---

## 📱 Les 2 Modes de Publication Directe TikTok

1. **Mode Brouillon Privé (Draft - Recommandé)** :
   - La vidéo arrive pré-découpée, sous-titrée et avec sa légende déjà prête directement dans tes brouillons TikTok.
   - **Avantage stratégique** : Tu peux, si tu le souhaites, y ajouter une musique gospel instrumentale tendance en 1 clic dans TikTok avant de cliquer sur "Publier", ce qui multiplie la portée par 3 à 5 !
2. **Mode Public Direct** :
   - La vidéo est publiée instantanément sur ton compte sans aucune intervention.

## 🚀 Comment Lancer un Nouveau TikTok en 1 Clic

1. Rends-toi sur l'onglet **Actions** de ton dépôt : **[Lancer la Machine TikTok](https://github.com/digrekarlito11-eng/tiktok-autopilot/actions)**.
2. Clique sur **"🚀 Usine de Production Vidéo TikTok (Prédications & Foi)"**.
3. Clique sur **"Run workflow"** :
   - Colle le lien de la prédication de l'homme de Dieu de ton choix.
   - Choisis le thème (par défaut : `gospel` avec or céleste et blanc éclatant).
   - Choisis le mode de publication (`draft` pour brouillon ou `public`).
4. Clique sur le bouton vert : **le robot s'occupe de tout.**
